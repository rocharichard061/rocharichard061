# GitHub Profile V3 — logotipos reais

1. Crie o repositório público `rocharichard061/rocharichard061`.
2. Envie `README.md` e a pasta `assets/` para a raiz do repositório.
3. Abra seu perfil para ver o README renderizado.
4. Opcional: abra `preview.html` localmente para ver uma apresentação experimental com hover e JS (não faz parte do perfil GitHub).

Os logotipos das tecnologias são os SVGs **originais do Devicon**, servidos por jsDelivr. Isso significa que precisam de conexão com internet para carregar, e não são formas tipográficas inventadas. Caso deseje hospedá-los no próprio repositório, baixe os SVGs das URLs no README e substitua os `src` por arquivos locais. Alguns ícones (por exemplo GitHub escuro) têm contraste reduzido em temas escuros; podem ser trocados pela versão branca/monocromática do mesmo projeto.

O JavaScript do HTML não funciona em READMEs do GitHub; as animações discretas do banner usam SVG. O projeto CommerceHub foi descrito apenas com funcionalidades confirmadas no repositório público.

Fonte dos logotipos: https://github.com/devicons/devicon

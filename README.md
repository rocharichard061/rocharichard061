## Sobre mim

Estudo Engenharia de Software e me especializo em back-end com Java. Meu dia a dia de estudo é construir: modelar um domínio, expô-lo por uma API REST com Spring Boot, persistir os dados em PostgreSQL e documentar e testar os endpoints com Swagger e Postman. Versiono tudo com Git e uso Docker para manter o ambiente reproduzível.

Escrevo código pensando em quem vai manter: responsabilidades separadas, regras de negócio isoladas e dados consistentes. É por isso que testes automatizados, segurança e arquitetura são os próximos assuntos da minha lista.

## Como eu trabalho

| Princípio | Como aplico |
| --- | --- |
| Modelagem de domínio clara | As classes e tabelas levam o nome do negócio, não da tecnologia |
| Separação de responsabilidades | Controller recebe HTTP, service concentra regras, repository acessa dados |
| Integridade dos dados | Validação na aplicação e constraints no banco |
| Código sustentável | Unidades pequenas, nomes diretos, mudanças localizadas |
| API documentada | Endpoints descritos no Swagger e testados no Postman |
| Evolução contínua | Cada projeto novo resolve uma lacuna do anterior |
